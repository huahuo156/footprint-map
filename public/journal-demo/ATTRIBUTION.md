# 示例照片

示例照片沿用原项目使用的 [marksui/China-Travel-Map](https://github.com/marksui/China-Travel-Map) 景点照片数据集，原始路径为 `assets/images/<地区>/<景点>.jpg`。

示例仅用于演示手帐布局，与个人数据库、上传照片分别保存。所有照片与名称对应关系可查看 `scripts/fetch-demo-photos.py`，其中保留了来源地区、景点名称和本地文件名。

图片已随项目保存，运行应用不需要访问 GitHub 或 CDN。使用 `python scripts/fetch-demo-photos.py` 可从原来源重新获取这些示例图片。
