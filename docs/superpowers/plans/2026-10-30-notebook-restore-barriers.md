# M1.3 手札归属与恢复结构屏障

继续已确认设计，使用 executing-plans/TDD；保留既有改动，不提交或发布。

- [x] 手札移入、返回画布、页删除、手札删除的旧结构令牌失败回归。
- [x] 先锁结构再改归属；只有实际影响画布归属或组成员的变化递增一次。页内移动、页排序和纯阅读状态不改画布令牌。
- [x] 恢复请求的multipart结构令牌传到worker，在恢复事务内检查；实际导入新对象/关系后递增一次，空导入不递增，归档版本不复用。
- [x] 真实API覆盖worker传参、并发、跨账号、回滚和内容/空操作不递增；全量、安全、恢复、E2E、审查与清理。

Ruling：页面间移动已在手札内的对象不改变画布归属，因此不增结构令牌；移入时如果从画布组移除成员仍递增。删除空页/空手札不递增，但若请求提供结构令牌仍检查它。恢复文件先暂存/校验，事务锁在资源登记及业务写入前取得。

Ruling：API错误处理原先仅透出INVALID_IMAGES码。真实worker测试发现布局冲突码被丢弃，因此只新增LAYOUT_CONFLICT、LAYOUT_MIGRATION_REQUIRED、INVALID_LAYOUT白名单，保持内部数据库错误不向客户端暴露。
