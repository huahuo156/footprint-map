# M1.3 迁移、建号与备份生命周期接入

继续执行已确认的[画布历史与保存设计](../specs/2026-10-29-canvas-history-save-design.md)，本批只接入数据库生命周期，后续再协调切换所有读写入口和画布状态。

目标：显式迁移可升级旧库，注册和 CLI 建号原子创建布局状态；新旧全量恢复点均可演练，个人 ZIP 不携带并发版本值。

- [x] 新建结构包含三类无符号 BIGINT 行版本和每账号结构状态；db:migrate 调用幂等迁移；API 启动只检查，不执行 DDL。
- [x] 注册与 db:create-user 复用事务建号服务；状态插入失败回滚账号，新增认证回归。
- [x] 全量备份支持完整旧/新结构，拒绝部分混合结构，精确保留新版本值；旧恢复点按旧结构恢复后需显式迁移。
- [x] 个人 ZIP 去除版本值，导入仍生成新 ID 和默认版本。
- [x] 新增实际 CLI 的独立随机库验证入口和 CI 步骤；已有 API、E2E、恢复夹具适配新建号约束。
- [x] 单元、安全、真实 API、恢复、浏览器、构建、审计、独立审查及专用测试环境清理。

约束：不操作个人业务数据库，不自动提交工作区，不启用尚未配套的条件保存协议。后续重点是业务写入口的版本递增与结构屏障，再统一启用快照和条件布局写入。
