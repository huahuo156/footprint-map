# M1.3 记录与删除结构屏障

继续已确认的画布历史保存设计，使用 executing-plans / TDD 在现有分支实施，不覆盖或提交既有改动。

- [x] HTTP 回归先失败，覆盖记录增改和四种对象删除入口的过期结构令牌与 legacy 递增。
- [x] saveEntry 在资源/业务写入前锁账号和结构；创建记录、增删照片、实际移除手札记录引用时递增一次，纯内容不递增。
- [x] /items、/photos、/photos/:id、/entries/:id 删除在同一事务检查结构、校验所有权、删除并递增；最后一个入口改为原子事务收集资源，提交后再回收文件。
- [x] 真实隔离 API 验证旧令牌拒绝、引用和令牌变化、失败回滚、跨账号与并发；全量及必要门禁、独立审查、环境清理和归档。

Ruling：原有照片内容更新不改坐标或旋转，因此不要求行版本；结构变化只更新账号令牌。创建到手札的新对象由外层事务统一递增一次。手札其他入口及恢复入口仍待下批。

Ruling：buildCanvas 按旅程、日期及照片排序派生相对布局；这些值变化也视为结构变化，以使旧布局快照失效。新增两个失败回归后接入 trip/date 检查，真实 API 验证双照片反转顺序只增结构令牌、行版本不变；独立审查复核通过。
