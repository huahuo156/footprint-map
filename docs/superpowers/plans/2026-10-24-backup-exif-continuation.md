# 备份与 EXIF 中断续作

用户要求继续完成 ZIP（照片与 JSON）导出和导入还原、可打印 PDF 留念册、EXIF 日期与位置预填。
沿用当前 React / Express / MySQL 结构，在原工作区保留并补齐中断留下的改动。

- [x] 备份：修复异步还原、组件中的旅程引用映射、文件校验及失败回滚；测试 ZIP 损坏和完整合并。
- [x] EXIF：测试并修复 JPEG 头遍历、日期和 GPS 校验；编辑时只同步主动修改的字段，保留每张照片自己的 EXIF；限制批量解析并发。
- [x] 留念册：在手札中提供打印预览，含封面、扉页、全部按序内页，复用内容渲染并等待照片加载；通过浏览器保存 PDF。
- [x] 更新使用文档，运行单元、API、构建与相关浏览器验证，记录环境限制。

实现选择：离线匹配附近 landmarks，未匹配时保留 GPS；不把私人照片位置发送给第三方。
实现选择：PDF 采用浏览器打印，避免部署浏览器服务，中文字体和照片沿用浏览器显示。

审查修复：拒绝循环色块分组、导出预检 1GB 上限（与还原一致）、仅预览打开时启用全页打印样式、保留原始时间戳与空封面字样、让还原封面沿用 cover- 文件清理约定。
验证：124 个单元测试、36 个 MySQL 集成测试；浏览器验证含真实 EXIF 图片、ZIP 下载/还原、6 页 A4 PDF（Poppler 渲染检查）。API 测试使用独立 3308 实例及含 test 的数据库，禁止针对用户数据库运行。
