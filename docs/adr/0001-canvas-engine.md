# ADR 0001：继续改善现有画布实现

- 日期：2026-10-29
- 状态：暂定，遵循长期计划的默认方向；替换方案尚未经过同场景原型验证
- 依据：源码基线 `936a9a5`；[交互盘点](../canvas-interactions.md)

## 背景

现有 React DOM 画布包含照片、文字/贴纸、手帐入口和嵌套色块，并通过业务接口保存；已具备框选、相机缩放、组移动和碰撞规划。眼前问题集中于输入生命周期和保存可信度，没有证据表明必须更换渲染引擎。

## 决策

本阶段保持现有引擎、数据格式和私有图片请求链路，先建立输入和相机边界，再设计历史命令与持久化。此决定是执行者依据长期计划作出的默认判断，不表示维护者批准了新 SDK、授权费用或数据迁移。

| 方案 | 对照片、手帐与分组的适配 | 代价与验证要求 |
| --- | --- | --- |
| 改善现有实现（当前默认） | 复用现有组件、接口、折叠层级和鉴权 | 自行维护输入与坐标边界；每个修复补针对性回归，无新增引擎依赖 |
| 局部 Moveable | DOM 卡片可作为目标，组变换和吸附可评估 | 需验证现有 scale/translate 与控件坐标、嵌套组、触屏、避让兼容；不能代替历史/保存层 |
| 完整 SDK：tldraw / Excalidraw | 提供通用画布基础，需要映射业务实体与资源 | 原型证明自定义照片/手帐、旧布局导入导出、权限、移动端、首屏分包及历史语义可行后才考虑迁移 |

包体和性能未测，不提供估计数字或“SDK 更快”的结论。未来对比必须保留现有首页分包门禁，并记录实际构建的增量、500 张档位帧耗时及内存。

## 授权与来源

2026-10-29 查阅 [tldraw 官方许可](https://tldraw.dev/community/license)：默认条款限开发使用，生产需要有效许可；是否适用商业或 hobby 条款需实施前再次核对，不能当作 MIT 依赖直接引入。

[Excalidraw 官方仓库](https://github.com/excalidraw/excalidraw) 标示 MIT；[Moveable 官方 API](https://daybrush.com/moveable/release/latest/doc/) 为局部变换评估入口。任何实际复用仍需锁定具体版本并审查其 LICENSE、依赖和署名；本次未新增包或复制第三方实现。

## 后果与重新评估条件

近期改动保持可审查，旧照片坐标和备份无需迁移；同时承担自行完善触屏、键盘和历史记录的成本。出现可重复的复杂输入/性能瓶颈，或局部实现成本明显超过适配成本时，重新评估。

重新评估必须使用同一组合成场景：横竖照片、长文字、贴纸、手帐、两层嵌套分组；比较正反框选、拖动取消、触屏、键盘、折叠、重载位置和私有图片。候选实现仅用隔离原型，不读写个人数据。没有实测结果前，此 ADR 不构成完成 SDK 选型验收的证明。
