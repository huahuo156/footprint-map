# 画布键盘、定位与选择入口盘点

日期：2026-10-31。依据当前工作区JourneyCanvas、CanvasItem及分组选择模型；是能力盘点，不是新交互设计或完成全部M1的证明。

| 能力 | 当前入口与行为 | 状态/边界 |
| --- | --- | --- |
| 进入/退出多选 | Tab定位「多选内容」后Enter；进入时聚焦画布；Escape或退出按钮结束 | 已有；编辑器、输入法组合、已处理事件和其他区域不截获画布快捷键 |
| 全选/清空 | 画布内Ctrl/Cmd+A，或选择栏的全选/清空按钮 | 已有；最多500项，分组为选择单位，超限不拆组 |
| 逐项与整组选中 | 选择模式下照片、分组标题或折叠封面按钮可键盘激活 | 已有；选择一个成员扩展到最外层整组，含折叠成员 |
| 撤销/重做 | 个人画布内Ctrl/Cmd+Z、Shift+Z和状态栏按钮 | 已有；首期只覆盖布局历史，编辑器内快捷键不操作画布历史 |
| 查看全部 | 「查看全部旅程」按钮，可通过Tab+Enter触发 | 已有；活动拖动/平移/框选期间及手帐打开时忽略，手势取消后恢复 |
| 旅程定位 | 概览中的旅程卡按钮，键盘激活后对准旅程 | 已有；本批补齐与概览相同的手势/手帐隔离 |
| 单对象键盘打开 | 非选择模式下照片/文字/手帐按钮键盘激活 | 已有；屏外项可能被可见性裁剪，不能等同于可用键盘遍历全部内容 |
| 方向键排版 | 多选后方向键1单位、Shift+方向键10单位；一次按键整体微调，可撤销/重做 | 已实现；仅已保存/idle即时状态受理，长按不连发，碰撞整批拒绝而不跳位 |
| 定位到任意选中内容 | 选择栏「定位选中」和画布内F | 已实现；只改相机，保持选择并返回画布焦点，不写布局或历史 |
| 任意多选共同移动 | 显式色块分组可刚性拖动；任意有效选择集可键盘整体微调 | 任意选择集的鼠标共同拖动仍缺失；键盘移动不能替代这一入口 |
| 锁定/层级/吸附 | 没有对应工具入口 | 缺失；碰撞避让不等同于吸附，渲染顺序不等同于层级命令 |

## 本批修复与验收

概览和旅程定位原先直接改变相机，绕过已有zoom的活动手势/手帐隔离。本批复现后统一早退规则，不积压请求、不自动取消手势、不改动布局或历史。组件用例覆盖五种活动手势、旅程定位及手帐打开；原生浏览器键盘激活概览按钮验证相机不跳变，取消后可正常定位且没有布局写入。详见[定位入口验证](verification/2026-10-31-canvas-navigation-guard.md)。
