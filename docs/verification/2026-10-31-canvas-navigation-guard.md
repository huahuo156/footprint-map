# M1.2 定位入口与活动手势隔离

## 根因与修复

现有zoom会在活动手势或手帐打开时直接返回；overview和focus却没有相同边界。拖动期间通过键盘聚焦并激活「查看全部旅程」，或平移期间激活旅程概览卡，会立即改写相机，使后续位移与原手势不一致；手帐打开时概览也可改变底层画布。

本批为overview和focus增加drag.current/notebookOpen边界，沿用已有缩放策略：活动期间忽略定位，不取消手势，也不排队重放。手势取消后入口恢复可用。没有新增键盘移动命令、定位快捷键或存储字段。
