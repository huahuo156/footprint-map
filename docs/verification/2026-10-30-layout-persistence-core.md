# M1.3 保存协调器核心

新增纯 createLayoutPersistence 状态服务，注入send，不依赖React、全局API或账号状态。它保存当前意图、已确认位置/字符串版本、至多一个不可变请求及独立历史，提供编辑/撤销/重做/重试、订阅、显式替换基线和销毁。

网络失败保留请求与当前编辑，停止自动发送；重试原样发送未知请求，确认版本后才提交新差异。409清除未知请求并阻止盲重试；显式基线替换才丢弃冲突编辑。未确认请求存在时拒绝刷新替换基线。401/销毁清空内存、abort并忽略迟到结果；订阅者同步退出时也不再启动transport。

回执要求全部对象且版本精确为expected+1；不完整回执按结果未知失败处理，不猜测版本。历史与持久化共用不可变位置校验。待保存差异最多500对象，包含未知请求确认后的可能差异，超限在新编辑前拒绝，避免拆分原子命令或发出超限请求。
