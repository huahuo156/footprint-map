# M1.3 业务写入口的对象锁工具

承接已确认的画布历史与保存设计及布局写入口盘点。保留既有工作区改动，本批没有提交、发布或操作业务数据库。

新增 `server/layout-versions.js` 的 `lockLayoutObjects`：调用者先取得账号结构锁，在同一事务内按稳定顺序锁对象；新版请求检查整批行版本，legacy 请求也能递增版本。每对象只允许递增一次，BIGINT 用字符串与 BigInt 精确保留。调用者负责事务回滚，不允许在捕获失败后继续提交。

验证：新增 9 项测试先运行，因工具尚不存在全部失败；实现后与结构锁和条件布局协议合计 24 项通过。全量 `npm test`：56 文件、389 项通过；lint、git diff --check 通过（后者有既有 CRLF 提示）。

边界：这是业务入口接入的共享基础工具，尚无运行路由调用；没有启用一致性 GET 或条件保存，没有改动前端。模拟连接用例不替代真实 MySQL 的事务、回滚与并发验收，后续入口接入时必须补齐。
