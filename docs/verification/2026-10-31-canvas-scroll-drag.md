# M1.2 父容器滚动中的拖动坐标

## 问题与修复

在已偏移的画布中开始拖动，再将父容器向左滚动20px、向上滚动100px，指针仍在原屏幕位置时，旧实现只使用client坐标差，照片/手帐/整组及相机平移没有补偿新的视口位置，导致内容偏离指针。框选此前已使用当前边界，因此不受同一问题影响。

begin/beginGroup现在记录通过既有viewportPoint得到的起始视口中心相对位置；move使用当前getBoundingClientRect重新投影指针，再计算活动位移。对象位移继续除以相机倍率，平移保持屏幕像素单位。视口尺寸变化同样纳入中心变化。

保留原client像素5px曼哈顿距离点击阈值，父容器滚动本身不把点击变为拖动；活动拖动中的缩放仍被阻断。取消继续恢复预览、释放捕获且不写入，正常松手只提交一次校正坐标。不改变碰撞、分组关系、版本协议或存储格式。
