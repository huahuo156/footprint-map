# P3 画布驻留与封面预算接线

日期：2026-10-31。用户再次要求全力推进并使用子代理，主线程与三条并行线完成画布接线、消费者适配及原生浏览器验证。

## 本轮实现

- JournalPage 经稳定的 CanvasImageResources 壳接入 JourneyCanvas。构建开关 VITE_CANVAS_IMAGE_RESIDENCY / VITE_CANVAS_IMAGE_CACHE 默认 false，缓存不能单独开启。关闭时不创建资源会话；切换策略、账号资源代际与固定 profile 时不按 epoch 重挂载整个编辑器。
- 照片卡片、折叠色块封面、旅程封面和手札封面统一竞争 48/24 个图片名额；未获名额渲染轻量占位，不创建 img 或请求。公共示例图片同样计入驻留上限。
- 详细节点统一计算照片、文字/贴纸、记录和手札，桌面最多120、平板最多60；非图片记录不占图片预算。完整业务、碰撞、选择和保存模型保留。
- 低倍网格提供轻量“进入局部”入口并支持键盘；到最大缩放仍重叠的溢出内容用每页50项的无图成员列表逐项打开或选择，避免永久不可达。2000项的分页助手检查覆盖全部成员。
- 焦点和拖动目标进入驻留优先级；普通旅程照片缩回封面模式时保留当前聚焦节点。概览入口保持在卡片上方，不被图片占位遮挡。
- Provider 新增 enabled 生命周期，并以代际 token 隔离停用后重新启用的旧缓存；测试确认策略切换保留未保存输入。
