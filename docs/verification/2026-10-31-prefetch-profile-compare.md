# P3预取、切档与P4对比续推记录

日期：2026-10-31。范围：预取租约、手势安全自动切档、三组性能对比工具与上次中断的拖动验收路径。

## 已合并实现

- 画布近视口候选接入预取租约，私有缩略图规范化去重，桌面最多8、平板最多4；不创建img、Object URL或主动解码。候选、scope、策略变化和卸载均释放旧租约。
- 可见图片需求遇到请求/字节压力时撤销纯预取资源，共享同源的display租约不会被取消；取消在途响应仍保留请求和字节预留直到实际结束。
- 视口宽度或粗指针变化更新目标profile；活动指针手势中保留当前预算，多指全部结束后一次切换。pointercancel、lostcapture、窗口blur均可解除等待。稳定壳与Provider token保留编辑器并屏蔽旧缓存。
- 对比工具构建独立临时输出，顺序运行旧路径、仅驻留、驻留+缓存，同一批合成缩略图和轨迹；报告原始样本、相对重复请求、预算met/missed/incomplete/N/A，绝不把短跑当十分钟压力验收。
